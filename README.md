# Portfólio — Henrique

Site pessoal de portfólio, construído em HTML, CSS e JavaScript puro (sem frameworks ou bibliotecas), como projeto de prática deliberada.

## Objetivo

Apresentar meus projetos, experiência e forma de trabalhar, com foco em fundamentos sólidos de front-end antes de migrar para uma stack com React e Node.js.

## Stack

- HTML5 semântico
- CSS3 
- JavaScript

## Estrutura do projeto

```
├── index.html
├── css/
│   ├── reset.css        # zera estilos padrão do navegador
│   ├── variables.css     # cores, fontes, espaçamentos
│   └── style.css         # layout geral
├── js/
│   ├── main.js            # ponto de entrada
│   ├── data/               # dados do site (perfil, projetos)
│   ├── render/              # transforma dados em HTML
│   └── ui/                   # interações (menu, tema)
└── assets/
    ├── imagens/
    ├── icones/
    └── cv-henrique.pdf
```
